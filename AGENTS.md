# PithosPandoras — контекст проекта

## Что это

Локальный сервис задач: один процесс, SQLite, MCP-сервер для агентов и страница
в браузере. Пишется на Rust. Имя проекта — **PithosPandoras**, пакет и бинарник —
`pithos-pandoras`.

## Где что

- `docs/Сервис-задач-архитектура.md` — архитектура, схема БД, инструменты, этапы M1–M5.
- `docs/АРХИТЕКТУРА-КОДА.md` — слои и границы модулей.
- `docs/РАЗРАБОТКА.md` — сборка, проверки, зависимости.
- `docs/ИНДЕКС.md` — как устроен индекс проекта.
- `src/` — код.
- `tools/` — скрипты обвязки.
- `.opencode/` — правила и скиллы для агентов.
- `home-dev-kit/` — справочный архив с рабочего компьютера. Не часть проекта,
  в индекс не попадает, ничего оттуда не переносим.

## Жёсткие правила

- Сначала архитектура, потом код. Схему БД и контракты MCP менять только вместе
  с записью в `docs/`.
- Один писатель в SQLite. Мутации — только через writer, чтение — параллельно.
- `workspace`, `task`, `role` обязательны. Значений по умолчанию и автосоздания нет.
- Ошибка приложения — `{code, message, hint, allowed}`. На пользовательском вводе
  не `panic`, не `unwrap`.
- Одна задача — один открытый этап. Отчёты не редактируются: новый круг — новый отчёт.
- Секреты в репозиторий не класть.
- 1С-инструменты, MCP и роли из `home-dev-kit` не использовать: это только пример.

## Сборка и проверки

```text
cargo run -- init --workspace PithosPandoras --root .
cargo run -- serve --db pithos-pandoras.db
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-features
tools/check.ps1        # всё сразу
```

## Индекс

Перед вопросом о структуре, вызовах и влиянии правки — граф:

```text
tools/index.ps1 query "..."
tools/index.ps1 explain "Symbol"
tools/index.ps1 affected "Symbol" -Depth 3
```

Точные строки, тексты ошибок и ключи конфигов — `rg`. После крупных правок —
`tools/index.ps1 update`. После коммита граф обновляет git-хук graphify.

## Сервис задач

Рабочее пространство: PithosPandoras

## MCP

Сервер на `/mcp` требует `Authorization: Bearer <ключ из pithos-pandoras.key>`.
Ключ в git не класть.

## Страница

`/` — доска, `/tasks/{number}` — карточка, `/search`, `/stats`, `/settings`.
Действия человека идут с подписью `человек` и роль не требуют.

## Память

- Сюда — только невыводимые, стабильные, влияющие на поведение факты.
- Детали и runbook — в `docs/`, здесь ссылка.
- Держать файл ≤ ~100 строк; при росте выносить детали в `docs/`.
