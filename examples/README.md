# Примеры правил

Здесь лежат примеры правил для клиентских проектов, которые работают с PiPa.
Это не действующий канон и не источник правды.

- **`rules/pipa-orchestration/`** — пример общего скилла агента, который ведёт
  задачи в PiPa. Канон контракта живёт в `1c-ninja-kit`: скилл `skill-pipa`,
  правило `rule-routes`, промпт роли «Коммандер». Копия здесь нужна для истории
  и как образец: по ней видно, как менялся контракт, но устанавливать её как
  действующие правила не нужно.

Правила разработки самого PiPa лежат отдельно — в `.opencode/skills/pithos-domain/`:
они относятся к этому репозиторию, а не к клиентскому проекту.
