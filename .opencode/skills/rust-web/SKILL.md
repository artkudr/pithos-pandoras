# Сервер и страницы

Обработчик — тонкий. Он разбирает запрос, зовёт сервис и отдаёт ответ. Правила
и SQL живут ниже.

## axum

```rust
use axum::{extract::State, http::StatusCode, response::IntoResponse, Json};

async fn get_task(
    State(app): State<AppState>,
    Path(number): Path<i64>,
) -> Result<Json<TaskView>, AppError> {
    let task = app.service.task_get("PithosPandoras", number).await?;
    Ok(Json(task.into()))
}
```

- Состояние — `AppState` с `Arc<Service>`, конфигом и writer-хэндлом.
- Экстракторы — `Path`, `Query`, `Json`, `HeaderMap`. Не тащи `Request` в сервис.
- Ошибки — `IntoResponse` для `AppError`; статус и JSON-тело в одном месте.
- Не вызывай `store` из обработчика.
- Не держи блокирующие вызовы в async: только `service`, который сам решает,
  где `spawn_blocking`.

## Страницы

- `askama` для шаблонов; шаблоны лежат рядом с `web`.
- `rust-embed` для встраивания шаблонов и статики в бинарник.
- Markdown отчёта рендерится с очисткой от опасного HTML.
- Картинка из `/files/<id>` вставляется в том месте текста, где стоит ссылка.
- Действия человека пишутся с подписью `человек`, без проверки ролей.
- Страница не содержит своей логики переходов: те же функции, что у MCP.

## MCP

- `rmcp` — сервер на `/mcp`, тот же порт, что у страницы.
- Каждый инструмент: имя, схема аргументов, обязательные поля, вызов сервиса.
- Ошибка — `{code, message, hint, allowed}`. Не отдавай `rusqlite::Error` и
  `anyhow::Error` как текст.
- Имя проекта приходит от агента; сервер его не угадывает и не читает
  `AGENTS.md`.
- Несколько клиентов одновременно — норма. Сервис не различает, чей это агент:
  важны ключ и имя роли в запросе.

## Файлы

- `/files/{file_id}` отдаёт файл только из задачи, к которой он привязан.
- Путь проверяется: не выходит за `root_path` проекта.
- MIME и размер — из записи; содержимое — с диска.
- Ссылка в отчёте — `/files/<id>`; при сохранении отчёта файл прикрепляется к нему.
- Чужой файл в ссылке — ошибка, а не «покажем что есть».

## Запуск

- Порт `8787`, только `127.0.0.1`.
- Для доступа по сети — явное разрешение и ключ.
- Ключ создаётся при первом запуске; страница получает его одноразовой ссылкой.
- `/events` — поток изменений для живой перерисовки; не заменяй им обычные запросы.

## Запрещено

- Бизнес-логика в обработчике.
- HTML-шаблон, который сам решает, можно ли закрыть задачу.
- `unwrap` на заголовках, путях и JSON.
- Отдача файла по произвольному пути из запроса.
