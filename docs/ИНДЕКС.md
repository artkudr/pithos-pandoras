# Индекс проекта

Индекс отвечает на вопросы о структуре: из чего состоит модуль, кто вызывает
функцию, что заденет правка. Точные строки и тексты ошибок ищет `rg`.

## Как устроено

Локальный `graphify` разбирает Rust через tree-sitter, строит граф и кладёт его
в `graphify-out/`:

| Файл | Что это |
|---|---|
| `graph.json` | полный граф: узлы, рёбра, сообщества |
| `GRAPH_REPORT.md` | краткий отчёт: ключевые узлы и связи |
| `graph.html` | интерактивная карта в браузере |

Код разбирается на машине. API-ключ не нужен, потому что используется
`--code-only`. Документы, PDF и картинки в индекс не попадают.

## Команды

```text
tools/index.ps1 build                 # первый граф
tools/index.ps1 update                # после структурных правок
tools/index.ps1 query "как устроен writer"
tools/index.ps1 explain "AppError"
tools/index.ps1 path "stage_start" "reports"
tools/index.ps1 affected "create_task" -Depth 3
tools/index.ps1 status                # есть ли граф
```

`query` ищет по словам в именах узлов, а не по полному вопросу. Если ответа нет,
попробуй имя из кода.

## Запасной путь

Если `graphify` не установлен:

```text
rg -n "pattern" src
cargo metadata --no-deps --format-version 1
cargo tree
```

`rg` читает `.ignore` и не заходит в `target/`, `graphify-out/` и
`home-dev-kit/`.

## Что не индексируется

- `target/` — сборка.
- `graphify-out/` — сам индекс.
- `home-dev-kit/` — справочный архив с рабочего компьютера.
- `*.db`, `*.db-wal`, `*.db-shm` — база.

Список — в `.graphifyignore` и `.ignore`.

## Обновление

- `update` переразбирает изменённые файлы, `build` — всё с нуля.
- После переименования модуля или функции лучше `build`.
- Если граф устарел, не выдавай его ответ за текущий: скажи, что нужно обновить.

## Границы

- Макросы, трейты и динамическая диспетчеризация могут разрешаться неточно.
  Спорный вывод проверяй по исходнику.
- Граф не заменяет `cargo check`, clippy и тесты.
- `graphify-out/` — локальный кэш. В git не коммитится, если не нужен общий
  граф для команды.

<details>
<summary>Технические детали</summary>

- Пакет PyPI: `graphifyy`, команда `graphify`.
- Версия проверяется `graphify --version`.
- `--cargo` добавляет в граф зависимости между крейтами из `Cargo.toml`.
- Настройки проекта — `.graphifyrc`: `query_budget=4000`, `query_depth=3`.
- Имена сообществ не генерируются: `cluster-only --no-label` оставляет
  `Community N`. Для имён нужен LLM-бэкенд и команда `graphify label`.
- `graphify opencode install` умеет добавлять плагин и блок в `AGENTS.md`.
  Здесь это не используется: правило про индекс уже лежит в `AGENTS.md` и
  скилле `project-index`.
