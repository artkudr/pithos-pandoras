# Установка

PithosPandoras — локальный сервис задач: значок в трее, страница в браузере
и MCP-сервер для агентов. Всё работает на одной машине, внешних сервисов
и установщика нет.

## Что нужно

Windows 10 или 11, 64 бита. Больше ничего доустанавливать не надо: база SQLite,
страницы и значки уже внутри файлов.

## Первый запуск

1. Распакуйте архив в постоянную папку, например `C:\PithosPandoras`.
2. Откройте в этой папке PowerShell и создайте проект:

   ```text
   .\pithos-pandoras.exe init --project PithosPandoras --root .
   ```

   Рядом появятся база `pithos-pandoras.db` и папка `Задачи`.

3. Запустите `pithos-pandoras-tray.exe`. В трее появится значок; щелчок по нему
   открывает страницу `http://127.0.0.1:8787/`.

Ключ доступа к серверу агентов создаётся сам при первом запуске. Показать его:

```text
.\pithos-pandoras.exe key
```

## Автозапуск

```text
.\tools\install-tray.ps1
```

Скрипт кладёт ярлык в «Автозагрузку» с рабочим каталогом приложения, чтобы база
и ключ нашлись. Ярлык можно удалить обычным способом.

Если PowerShell отказывается запускать скрипт, снимите метку «скачано
из интернета»:

```text
Unblock-File .\tools\install-tray.ps1
```

## Подключение агента

Адрес MCP: `http://127.0.0.1:8787/mcp`. Заголовок —
`Authorization: Bearer <ключ>`, ключ печатает команда `key` выше.

<details>
<summary>Пример для opencode.json</summary>

```json
{
  "mcp": {
    "servers": {
      "pithos": {
        "type": "remote",
        "url": "http://127.0.0.1:8787/mcp",
        "headers": { "Authorization": "Bearer ВСТАВЬТЕ_КЛЮЧ" }
      }
    }
  }
}
```

</details>

## Где что лежит

Рядом с приложением:

- `pithos-pandoras.db` — база задач; `pithos-pandoras.key` — ключ доступа;
- `pithos-pandoras.log` — журнал трея, появляется после его запуска;
- `Задачи/` — папки задач проекта по умолчанию.

Копия базы (`backup`) кладётся в `backups/`. Файлы задач в копию не входят:
их копируют вместе с папкой проекта.

## Обновление

Остановите приложение, замените exe на новый и запустите снова. База мигрирует
вперёд сама; откат на старую версию не предусмотрен. Перед заменой сделайте
копию: `.\pithos-pandoras.exe backup`.

## Если не работает

```text
.\pithos-pandoras.exe doctor
```

Команда проверяет схему, целостность базы, открытые этапы, пропавшие файлы
и занятость порта 8787. Подробности запуска — в `pithos-pandoras.log`.
